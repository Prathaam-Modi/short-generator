# short-generator
Drop box and state for the daily Silicon Empire Short. Public on purpose: Zapier downloads each video from a raw link here.
- `drop/` temporary MP4s (added, uploaded to YouTube, then deleted by the daily task)
- `state/published.md` topic log (never repeat a topic)
- `assets/toon-host-style.zip` Toon Host style, restored when the cloud workspace is fresh
